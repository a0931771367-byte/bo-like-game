# 封測背景重繪（風格對齊現有角色）

罐子 10/29 回報背景與角色不相容。原因：舊背景是厚塗寫實風，角色是平塗粗描邊 Q 版；地面又是土層剖面，角色像站在平台邊緣。
做法：保留角色與敵人，背景重畫成角色同款畫風（平塗、兩階陰影、深色粗描邊），走道改成平坦草地。
